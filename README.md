# Open Source Software Audit Toolkit

## Overview

This project is a Linux-based auditing toolkit developed as part of an Open Source Software assignment. The toolkit uses Bash scripting to automate system inspection, software verification, directory analysis, log monitoring, and report generation. The project demonstrates the practical use of Linux command-line tools, shell scripting, and Git-based workflows.

## Software Chosen

**Git** is an open-source version control system used to track changes in source code, manage project history, and support collaboration in software development projects.

## Features

* Collects system information and environment details
* Verifies Git installation and package availability
* Audits directory contents and structure
* Analyzes system log files
* Generates a project manifesto/report

## Technologies Used

* Bash Shell Scripting
* Linux
* Git
* GitHub

## How to Run

Make the scripts executable:

```bash
chmod +x script1.sh
chmod +x script2.sh
chmod +x script3.sh
chmod +x script4.sh
chmod +x script5.sh
```

Run any script using:

```bash
./script1.sh
```

Replace `script1.sh` with the desired script name.
